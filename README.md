# 名刺管理アプリ (CardVault) - ご利用ガイド

本アプリは、専用のデータベースを使わず、**お客様のGoogleドライブ**を安全なデータベースおよび画像ストレージとして使用する「完全個人向け名刺管理PWAアプリ」です。

スマホで快適にスワイプ操作でき、アルファベット検索やタグ検索が可能です。

---

## 🚀 動作に必要な準備：Google Cloud 設定

アプリからご自身のGoogleドライブにアクセスできるようにするため、Google Cloud Consoleで無料の「OAuthクライアントID」を1つ作成する必要があります。

### OAuthクライアントIDの取得手順（所要時間：5分）

1. **Google Cloud Console** にアクセスします。
   [https://console.cloud.google.com/](https://console.cloud.google.com/)
2. 画面上部で新しいプロジェクト（例：「MyBusinessCardApp」）を作成し、選択します。
3. 左メニューの「APIとサービス」＞「ライブラリ」を開き、検索窓で **「Google Drive API」** を検索して**「有効にする」**をクリックします。
4. 左メニューの「APIとサービス」＞「OAuth同意画面」を開きます。
   - ユーザータイプは **「外部 (External)」** を選択して作成します。
   - アプリ名（例：「CardVault」）とサポートメールアドレス、デベロッパーの連絡先メールアドレスを入力して保存します。
   - **スコープの追加:** 今回は不要（そのまま次へ）。
   - **テストユーザーの追加:** **重要！** ご自身のGoogleアカウントのメールアドレスを必ず登録してください（テストモード中はこのアカウントのみログイン可能です）。
5. 左メニューの「APIとサービス」＞「認証情報」を開きます。
   - 画面上部の「+ 認証情報を作成」から **「OAuth クライアント ID」** を選択します。
   - アプリケーションの種類は **「ウェブ アプリケーション」** を選択します。
   - 名前を入力します（例: 「CardVault Web」）。
   - **承認済みの JavaScript 生成元:**
     アプリをデプロイしたURL、またはローカル開発用URL（例: `http://localhost:8000` または `http://localhost:5173`）を入力します。
     > [!IMPORTANT]
     > Googleログインの仕様上、`localhost` 以外のIPアドレス（例: `http://192.168.x.x`）は生成元として登録できません。実機スマホでテストする場合は、後述の「スマホでのテスト方法」を参照してください。
   - 「作成」をクリックすると、**「クライアント ID」**（`xxxx.apps.googleusercontent.com`）が表示されるのでコピーします。

## 🛠️ ローカルでの起動方法

Node.jsがインストールされているため、以下の手順でローカルサーバーを即座に起動できます。

1. **コマンドプロンプトやPowerShellを開きます。**
2. **プロジェクトのディレクトリに移動します。**
3. **ローカルサーバーを起動します。**
   ```bash
   npx http-server -p 8000
   ```
4. ブラウザで `http://localhost:8000` にアクセスします。
5. アプリの「初期設定」ボタンを押し、先ほどコピーした **OAuth クライアント ID** を貼り付けて保存します。
6. 「Googleアカウントでサインイン」を押し、テスト登録したご自身のアカウントでログインします。

## 📱 スマホ実機でのテスト・インストール方法 (PWA)

Googleログイン（OAuth）はセキュリティ上、暗号化された接続（`https`）または `localhost` のみで動作します。スマホ実機でテスト・使用するには以下の方法のいずれかを推奨します。

### 方法A：無料のホスティングサービスにデプロイする（最も簡単・おすすめ）
GitHub Pages、Netlify、Vercel などにファイルをアップロード（デプロイ）します。
これらは自動的に `https://` で始まるURLを発行してくれるため、何の設定もなくスマホで動作します。

**例：GitHub Pagesへのデプロイ手順**
1. GitHubにリポジトリを作成し、本プロジェクトのファイルをプッシュします。
2. リポジトリの「Settings」＞「Pages」を開き、Sourceを「Deploy from a branch」にしてメインブランチ（`/root`）を指定して保存します。
3. 数分後に発行される `https://<ユーザー名>.github.io/<リポジトリ名>/` をコピーします。
4. Google Cloud Console の「承認済みの JavaScript 生成元」に、このURLを追加します。
5. スマホのChromeでこのURLを開き、メニューから**「ホーム画面に追加」**を選択すると、スマホにアプリとしてインストールされます！

### 方法B：ngrok等でローカルをHTTPS公開する（開発用）
PCのローカルサーバーを一時的に外部HTTPS公開するツール（`ngrok` や `LocalTunnel`）を使用します。
```bash
npx ngrok http 8000
```
発行された `https://xxxx.ngrok-free.app` 宛にスマホからアクセスします。（Google Cloud ConsoleのJavaScript生成元にもこのURLを追加する必要があります）
